# 语文资料整理汇总平台

📚 一个为高三学子打造的语文备考资源导航页，汇集“理解性默写”与“课下注释”两大核心模块，持续更新中。。。

🌐 **访问地址**：[mz2709.cn](http://mz2709.cn)
💻 **适配说明**：为保障浏览体验，本平台目前**仅支持电脑端访问**，手机端打开会提示“请在电脑端访问”。
